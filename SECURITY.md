# Security Policy

## Supported Versions

Security fixes are generally provided for the latest published release.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Older versions | No |

As the project develops, supported versions may change.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues or discussions.**

Instead, use GitHub's private vulnerability reporting feature:

https://github.com/isaacm0880/Minecraft-Playden-Packager/security/advisories/new

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Affected versions and operating systems.
- Relevant logs or proof-of-concept details, with secrets and personal information removed.
- Any suggested mitigations, if known.

Reports will be reviewed as availability permits. No specific response or remediation timeframe is guaranteed.

Please avoid accessing other users' data, disrupting services or publicly disclosing an unpatched vulnerability before coordinated disclosure.

## Scope

Security reports may include vulnerabilities involving downloaded or imported files, archive extraction, filesystem operations, command execution, dependency handling, and packaged application distributions.

Ordinary bugs, feature requests and compatibility problems should be reported through GitHub Issues instead.
